# 🌿 Day 01 — Field Notes: Travel Magazine

A semantic HTML article template styled with a warm off-white background and sage-green accents.

## ✨ Project Overview

Field Notes is a simple travel magazine article page built to practise semantic HTML structure and foundational CSS styling.

## 🎯 Learning Objectives

- Use semantic HTML elements to organize article content.
- Create a clear heading hierarchy using H1, H2, and other appropriate headings.
- Apply a consistent type scale for headings and body text.
- Use CSS custom properties (`:root`) to manage reusable design values.
- Build a responsive layout for desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Custom Properties
- Responsive Web Design

## 🎨 Design

- **Background:** Warm off-white
- **Accent:** Sage green
- **Text:** Dark grey
- **Layout:** Article-focused travel magazine design

## 📱 Responsive Testing

The website was checked at the following viewport widths:

- Desktop: 1440px
- Tablet: 768px
- Mobile: 375px
